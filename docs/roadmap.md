# Roadmap

## Phase 1: Command Line Tool

- Connect to ELM327/STN adapters.
- Read common live PIDs.
- Read stored and pending trouble codes.
- Save JSON snapshots.

## Phase 2: Garage Diagnostics

- Add repeated live polling.
- Add CSV logging.
- Add clear-code command with confirmation.
- Add adapter detection diagnostics.

## Phase 3: Raspberry Pi Display

- Add a full-screen live data view.
- Add warning thresholds.
- Add startup auto-connect behavior.

## Phase 4: Foxbody Ecosystem

- Add a Microsquirt data adapter.
- Add BCM/Pico data adapter.
- Let the UI switch between OBD2, Microsquirt, and BCM sources.
